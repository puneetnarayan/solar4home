# Solar4Home

React + Vite household solar planning calculator.

## Local
`npm install`, then `npm run dev`.

## Vercel
Framework: Vite · Build: `npm run build` · Output: `dist`.

## Assumptions
Estimated generation uses editable specific yield (default 4.5 kWh/kWp/day) and performance factor. Roof potential uses editable planning density (default 0.10625 kW/m²). Figures are preliminary estimates, not a site survey, structural assessment, DISCOM approval, subsidy guarantee, quotation or generation warranty. Verify local rules before quoting.
